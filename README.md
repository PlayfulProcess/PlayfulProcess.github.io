# playfulprocess.github.io

The public umbrella site of **PlayfulProcess** — served by GitHub Pages at
https://playfulprocess.github.io.

Only explicitly promoted work lives here. The writing itself is drafted in a
private studio; publishing a piece means deliberately copying its built page
into this repo. If something isn't here, it isn't published.

## Work in progress

This site is a work in progress. I published it mainly so the pages could be served, and it
isn't finished. Corrections and suggestions are welcome through issues and pull requests (the
writing itself stays all rights reserved, as above).

The idea behind [recursive.eco](https://recursive.eco) is a hypothesis, not a claim: that we may
need to learn together how to create the conditions for recursive eco-improvement, rather than
race toward recursive self-improvement.

If your work appears here and you'd like it featured differently, removed, or given a shelf of
your own, please write to pp@playfulprocess.com.
